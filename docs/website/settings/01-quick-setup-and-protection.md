# Quick Setup and Protection

> **Included in Free**

## Quick Setup

| Option | What it does |
|---|---|
| Active Captcha Service | The provider every protected form uses. |
| Site Key / Secret Key | Keys from the provider. Saved secrets are never printed back. |
| Score Threshold (v3) | Lowest score accepted. Higher is stricter. |
| HMAC Key, Complexity, Challenge Expiration, Auto Verify, Hide Logo (ALTCHA) | Self-hosted challenge settings. |

## Protection

One switch per form, grouped by plugin. A switch that is off means that form is not checked. See Protected Forms for the full list.
