# Login Widget and Block

> **Included in Free**

The plugin adds an AJAX login form as a widget and as the Login block (`wbc/login-widget`).

## Behaviour

- Submitting does not reload the page. Errors show above the form in the theme's notice style.
- After a failed attempt the CAPTCHA is reset so the visitor can try again.
- A successful login redirects to the page set in the block, or home.
- Turn it on with Protection > WordPress Core Forms > Login Form.

The widget follows light and dark mode in Reign, BuddyX and BuddyX Pro.
