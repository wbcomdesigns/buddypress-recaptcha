# Installation and First Setup

> **Included in Free**

## Install

1. Go to Plugins > Add New, search for "Wbcom CAPTCHA Manager", then click Install Now and Activate.
2. Open WB Plugins > CAPTCHA.

## Choose a provider and add keys

1. Open the Quick Setup tab.
2. Under Step 1, pick the active CAPTCHA service.
3. Under Step 2, paste the site key and secret key from the provider, then save.

ALTCHA needs no account: it generates its own key.

No CAPTCHA shows and no form is protected until the provider's keys are saved.

## Turn protection on

1. Open the Protection tab.
2. Switch on each form you want covered and save.
3. Open the form in a private window. The widget should show above the submit button.

The Overview tab shows the active provider, any key problem and the most recent rejected submissions.
